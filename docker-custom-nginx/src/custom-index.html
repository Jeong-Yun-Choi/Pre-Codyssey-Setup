도커 커스텀 이미지 만드는 법

1. 기존 이미지를 내려받는다.

docker pull 내려받고자 하는 이미지명

2. 도커파일 만들기 전에 빈 도커파일을 생성한다.

touch Dockerfile

3. 도커파일을 열어서 다음 내용을 기입한 후 저장한다.

FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html

4. 사용할 웹 페이지를 제작한다.

5. 커스텀 이미지를 빌드한다.

docker build -t custom-nginx .

6. 커스텀 이미지로 컨테이너를 실행한다.

docker run -d --name 컨테이너명 -p 8080:80 custom-nginx

7. 컨테이너 실행 성공 여부를 확인한다.

docker ps

8. 웹 브라우저에서 결과를 확인한다.
